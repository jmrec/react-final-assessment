Phase 2 · Front-End Module · Build a React SPA on top of the Spring Boot API

Time limit: 3 hours  •  Total: 100 points  •  Passing score: 70

1. Overview

You are given a working Phase 2 Spring Boot back-end for a coffee shop (folder phase2-solution/). It exposes a REST API for the menu and orders, plus an agentic AI endpoint (POST /agent) backed by a local Ollama model and tool-calling.

Your task is to build a React (Vite) single-page front-end named coffee-shop-ui that consumes this API. Your submission is graded on four skill areas: CRUD operations, React Router, React Hooks (including a custom hook), and integrating the agentic AI chat.

A complete reference solution ships in the coffee-shop-ui/ folder. Instructors: use it as the answer key. Candidates: it is hidden during the exam.

2. Setup & Prerequisites

  • Node.js 18+ and npm
  • JDK 17+ and Maven (to run the provided back-end)
  • A free Google Gemini API key from Google AI Studio, exported as GEMINI_API_KEY (only needed for the AI task)

Start the back-end

cd phase2-solution/phase2-solution
# AI task only: export your free Gemini key first
#   PowerShell:  $env:GEMINI_API_KEY = "your-key"
#   bash:        export GEMINI_API_KEY=your-key
mvn spring-boot:run
# API is live on http://localhost:8080

Scaffold your front-end

npm create vite@latest coffee-shop-ui -- --template react
cd coffee-shop-ui
npm install
npm install react-router-dom
npm run dev   # http://localhost:5173
CORS is already configured on the back-end for http://localhost:5173. You may call the API directly, or add a Vite dev proxy for /api.

4. Tasks

Task A — Project & API layer 10 pts

  • Vite + React project runs with npm run dev
  • A single API/service module wraps all fetch calls (no inline URLs scattered in components)
  • HTTP errors are detected (non-2xx) and surfaced, not swallowed

Task B — CRUD: Menu management 30 pts

  • Read: list all menu items in a table/grid with name, category, price, availability
  • Create: a form that POSTs a new item and shows it in the list
  • Update: edit an existing item (pre-filled form) and PUT the changes
  • Delete: remove an item with a confirmation step; list updates without a full reload
  • Loading and error states are shown for each operation

Task C — React Router 20 pts

  • App wrapped in a router; at least 4 routes (e.g. Home, Menu, Orders, Barista)
  • A persistent nav bar using NavLink with an active-link style
  • At least one dynamic route param (e.g. /menu/:id/edit) read via useParams
  • Programmatic navigation after an action (e.g. useNavigate after save) and a catch-all/404 redirect

Task D — Hooks 20 pts

  • Correct use of useState and useEffect (data fetch on mount, cleanup where needed)
  • At least one custom hook (e.g. useMenu) that encapsulates data + actions and is reused by a component
  • No dependency-array bugs / no infinite render loops; derived values via useMemo where sensible

Task E — Agentic AI chat 15 pts

  • A chat page that POSTs plain text to /agent and renders the reply
  • Maintains a running conversation log (user + agent bubbles)
  • Shows a "thinking" indicator while the agent works (it may call tools and take seconds)
  • Demonstrates a multi-step request, e.g. "show available coffees, then order a latte and tell me the total", and the placed order appears on the Orders page

Task F — Code quality & UX 5 pts

  • Clear component structure, sensible names, no dead code or console spam
  • Reasonable styling and a usable, responsive layout
